# Add New File

[ダウンロード](https://github.com/31mskz10/alfred-workflows/releases/download/Add_New_File/Add.New.File.alfredworkflow) · [一覧へ戻る](../README.md)

FinderまたはPath Finderで開いているフォルダに、空のファイルを作成します。

## 必要なもの

- macOS、Alfred Powerpack
- FinderまたはPath Finder
- 作成先フォルダへの書き込み権限

## 初期設定

追加のワークフロー設定は不要です。初回実行時にアプリの操作許可を求められた場合は、AlfredからFinderまたはPath Finderへの操作を許可してください。

## 使い方

1. FinderまたはPath Finderで作成先のフォルダを開き、そのウインドウを最前面にします。
2. Alfredを呼び出し、`nf ファイル名` を入力します。例: `nf memo.txt`
3. Enterを押すと、開いているフォルダに空のファイルが作成されます。

選択中のサブフォルダではなく、現在のウインドウで開いているフォルダが作成先です。既存ファイルと重複しない名前を指定してください。中間フォルダは作成されません。
