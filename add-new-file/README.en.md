# Add New File

[日本語](README.md) · [Download](https://github.com/31mskz10/alfred-workflows/releases/download/Add_New_File/Add.New.File.alfredworkflow)

Create an empty file in the folder open in Finder or Path Finder. Requires macOS and Alfred Powerpack.

## Usage

1. Open the destination folder in Finder or Path Finder and keep that window frontmost.
2. Type `nf file-name` in Alfred and press Return, for example `nf memo.txt`.
3. A notification shows the path of the new file.

Without a Finder window, the file is created on the Desktop. An existing file with the same name is never overwritten; a notification tells you instead. File names cannot contain `/` or `:`. Grant automation permissions when prompted.
