# Alfred Workflows

macOSでのファイル操作、アプリの起動、設定の切り替えを行うAlfredワークフロー集です。

利用にはAlfred 5以降とAlfred Powerpackが必要です。Open with ApplicationとApplication GroupはAlfred 6が必要です。ワークフロー名をクリックすると、使い方とダウンロードリンクを確認できます。

## ワークフロー一覧

| ワークフロー名 | 概要 |
| --- | --- |
| [Open with Application](open-with-application/README.md) | FinderまたはPath Finderで選択中のファイル・フォルダを指定のアプリで開く。 |
| [OpenIn Temporary Switch](openin-temporary-switch/README.md) | OpenInのルールを一時的に切り替え、指定した分数の経過後に戻す。 |
| [CleanShot X Actions](cleanshot-x/README.md) | CleanShot Xの撮影・録画などのアクションを検索・実行する。 |
| [Toggle Dark Mode](toggle-dark-mode/README.md) | Macのダークモードとライトモードを切り替える。 |
| [Add New File](add-new-file/README.md) | FinderやPath Finderで開いているフォルダに新規ファイルを作成する。 |
| [Change Profile](change-profile/README.md) | Karabiner-ElementsのProfileを切り替える。 |
| [Execute ImageOptim](execute-image-optim/README.md) | 選択中の画像、または開いているフォルダの画像をImageOptimで圧縮する。 |
| [Application Group](application-group/README.md) | 画面で作成したアプリのグループを一括起動し、ウインドウ配置も再現する（Alfred 6）。 |

## インストール

1. 一覧から利用したいワークフローを選び、使い方と必要なアプリを確認します。
2. 個別ページの「ダウンロード」から `.alfredworkflow` ファイルを取得します。
3. ダウンロードしたファイルを開き、Alfredにインポートします。
4. 個別ページの説明に従って設定し、Alfredから実行します。
