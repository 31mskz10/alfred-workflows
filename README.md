# Alfred Workflows

macOSでのファイル操作、アプリの起動、設定の切り替えを行うAlfredワークフロー集です。

利用にはAlfred Powerpackが必要です。ワークフロー名をクリックすると、使い方とダウンロードリンクを確認できます。

## ワークフロー一覧

| ワークフロー名 | 概要 |
| --- | --- |
| [Open with Application](open-with-application/README.md) | FinderやPath Finderで選択中のファイル・フォルダを、指定したアプリケーションで開く。 |
| [OpenIn Temporary Switch](openin-temporary-switch/README.md) | OpenInのルールを一時的に切り替える。 |
| [CleanShot X Actions](cleanshot-x/README.md) | CleanShot XのアクションURLを検索・実行する。 |
| [Toggle Dark Mode](toggle-dark-mode/README.md) | Macのダークモードとライトモードを切り替える。 |
| [Add New File](add-new-file/README.md) | FinderやPath Finderで選択中のフォルダに新規ファイルを作成する。 |
| [Change Profile](change-profile/README.md) | Karabiner-ElementsのProfileを切り替える。 |
| [Execute ImageOptim](execute-image-optim/README.md) | 選択中のフォルダ内の画像をImageOptimで圧縮する。 |
| [Launch Applications](launch-applications/README.md) | あらかじめ設定した複数のアプリケーションを一括起動する。 |

## インストール

1. 一覧から利用したいワークフローを選び、使い方と必要なアプリを確認します。
2. 個別ページの「ダウンロード」から `.alfredworkflow` ファイルを取得します。
3. ダウンロードしたファイルを開き、Alfredにインポートします。
4. 個別ページの説明に従って設定し、Alfredから実行します。

Change ProfileはKarabiner-Elementsのプロファイル名、Launch Applicationsは起動するアプリなど、利用環境に合わせた設定が必要です。
