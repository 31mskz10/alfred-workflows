# OpenIn Temporary Switch

[ダウンロード](https://github.com/31mskz10/alfred-workflows/releases/download/OpenIn_Temporary_Switch/OpenIn.Temporary.Switch.alfredworkflow) · [一覧へ戻る](../README.md)

OpenInのルールを一時的に切り替え、指定した分数が経過すると既定のルールに戻します。

## 必要なもの

- macOS、Alfred Powerpack
- OpenInと、切り替え対象・復帰先のルール
- `/usr/bin/python3` でPython 3を実行できる環境（標準ライブラリの `sqlite3` を使用）

## 初期設定

1. OpenInで切り替え対象のルールを作成し、名前の先頭に `[Mode]` を付けます。例: `[Mode] Work`、`[Mode] Private`
2. 復帰先として `Default` という名前のルールを用意します。別の名前を使う場合は、次の設定で指定します。
3. AlfredでこのワークフローのConfigure Workflowを開き、設定を確認します。

| 設定 | 初期値 | 内容 |
| --- | --- | --- |
| デフォルトのRule名 | `Default` | 復帰先のルール名。OpenIn側の名前と完全に一致させます。 |
| Modeの接頭辞 | `[Mode]` | 一覧に表示するルール名の接頭辞。 |
| デフォルトの分数 | `10` | 分数を指定しない場合の復帰時間。正の整数を指定します。 |
| 自動復帰 | 有効 | 指定時間後に既定のルールへ戻します。 |
| OpenIn DBのパス | 空欄 | 通常は空欄で利用します。別の保存先を使う場合のみ絶対パスを指定します。 |
| OpenIn.app のパス | 空欄 | ApplicationsまたはそのSetappフォルダから自動検出します。見つからない場合は絶対パスを指定します。 |
| フォールバックブラウザのパス | `/Applications/Safari.app` | ルールに対応するアプリが見つからない場合の表示アイコンに使用します。 |

DBの保存先は、初期状態ではホームフォルダ内の `Library/Group Containers/4QE86VV38D.app.loshadki.OpenIn/Library/Application Support/OpenIn/local.sqlite` です。パスを手動入力する場合、`~` や環境変数は使わず絶対パスで指定してください。

## 使い方

1. Alfredで `oi` を入力します。`[Mode]` 付きのルールが、接頭辞を除いた名前で表示されます。
2. ルールを選び、Enterを押すと切り替わります。初期設定では10分後に `Default` に戻ります。
3. 時間を変更する場合は `oi 30` のように入力し、30分後に戻すルールを選びます。

一覧から `Default`（設定を変更した場合はそのルール名）を選ぶと、すぐに既定のルールへ戻ります。自動復帰を無効にした場合、または `oi 0` で切り替えた場合は、手動で戻すまで切り替え先が維持されます。

## 切り替え時の動作と注意点

- 切り替え時はOpenInを終了し、設定DBを更新して再起動します。
- すべてのルールを無効にしてから、選択したルールだけを有効にします。接頭辞のないルールも無効化の対象です。
- 復帰時は既定のルールだけを有効にします。切り替え前の複数ルールの状態は復元しません。指定した復帰先が存在しない場合は、すべてのルールが無効になります。
- 新しい切り替えや手動復帰を行うと、前の自動復帰予約は取り消されます。Macの再起動をまたいで予約は保持されません。
- OpenInの内部DBを直接更新するため、OpenInの更新でDB構造が変わると利用できなくなる可能性があります。使用前に設定のバックアップを取ってください。
