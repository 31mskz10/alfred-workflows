# OpenIn Temporary Switch

[English](README.en.md) · [ダウンロード](https://github.com/31mskz10/alfred-workflows/releases/download/OpenIn_Temporary_Switch/OpenIn.Temporary.Switch.alfredworkflow) · [一覧へ戻る](../README.md)

OpenInのルールを一時的に切り替え、指定した分数が経過するとデフォルトのルールに戻します。

## 必要なもの

- macOS、Alfred 5以降、Alfred Powerpack
- OpenIn（App Store版またはSetapp版）と、切り替え対象・復帰先のルール

## 初期設定

1. OpenInで切り替え対象のルールを作成し、名前の先頭に `[Mode]` を付けます。例: `[Mode] Work`、`[Mode] Private`
2. 復帰先として `Default` という名前のルールを用意します。別の名前を使う場合は、次の設定で指定します。
3. AlfredでこのワークフローのConfigure Workflowを開き、設定を確認します。

| 設定 | 初期値 | 内容 |
| --- | --- | --- |
| 言語 | 自動 | 表示する文言の言語。自動はmacOSの最優先言語が日本語なら日本語、それ以外は英語。 |
| キーワード | `oi` | Alfredで入力するキーワード。 |
| デフォルトのRule名 | `Default` | 復帰先のルール名。OpenIn側の名前と完全に一致させます。 |
| Modeの接頭辞 | `[Mode]` | 名前がこの文字列で始まるルールを一覧に表示します。 |
| デフォルトの分数 | `10` | 分数を入力しなかったときの、自動復帰までの分数。 |
| 自動復帰 | 有効 | 指定した分数の経過後にデフォルトのルールへ戻します。 |
| OpenIn DBのパス | 空欄 | 空欄なら標準の場所を使います。 |
| OpenIn.appのパス | 空欄 | 空欄なら `/Applications` と `/Applications/Setapp` から探します。 |

## 使い方

1. Alfredで `oi` を入力します。`[Mode]` 付きのルールが、接頭辞を除いた名前と、ルールで開くアプリのアイコン付きで表示されます。
2. ルールを選び、Enterを押すと切り替わります。初期設定では10分後に `Default` に戻ります。
3. 分数を変える場合は `oi 30` のように入力します。`oi 30 work` や `oi work 30` のように名前と組み合わせると、ルールを絞り込めます。分数は先頭か末尾に、0〜10080（7日）の整数で入力します。先頭か末尾にある数字は分数として扱うため、ルール名の数字では絞り込めません。

一覧から `Default`（設定を変更した場合はそのルール名）を選ぶと、すぐにデフォルトのルールへ戻ります。自動復帰を無効にした場合、または `oi 0` で切り替えた場合は、手動で戻すまで切り替え先が維持されます。

## 切り替え時の動作と注意点

- 切り替え時はOpenInを終了し、設定DBを更新して再起動します。OpenInが5秒以内に終了しない場合は、設定DBを変更せずに中止します。このとき、OpenInが後から終了して再起動されないことがあります。OpenInを終了していた場合も、切り替えと自動復帰のたびにOpenInを起動します。
- 切り替えるのは、`[Mode]` 付きのルールがあるハンドラ（Webブラウザなど）のルールだけです。そのハンドラでは選択したルールだけを有効にし、接頭辞のないルールも含めてほかは無効にします。選択したルールがないハンドラでは、デフォルトのルールを有効にします。ほかのハンドラのルールは変更しません。
- 復帰時は、同じハンドラでデフォルトのルールだけを有効にします。切り替え前の状態は復元しません。
- `[Mode]` 付きのルールがあるハンドラのどれかに復帰先のルールがない場合は、一覧にエラーを表示し、切り替えません。
- 新しい切り替えや手動での復帰が成功すると、前の自動復帰の予約は取り消されます。切り替えに失敗した場合、前の予約は残ります。Macを再起動すると予約は消えます。予約中にConfigure Workflowの設定を変えても、自動復帰は予約した時点の設定で動きます。スリープ中も時間は進み、復帰の時刻を過ぎていればスリープ解除後に戻ります。
- 自動復帰に失敗した場合は、理由を通知します。
- OpenInの内部DBを直接更新するため、OpenInの更新でDBの構造が変わると使えなくなる可能性があります。使用前に設定のバックアップを取ってください。

1.0.0からの変更点: Python 3が不要になりました。英語表示に対応しました。「フォールバックブラウザのパス」の設定は削除し、アプリが見つからないルールにはOpenInのアイコンを表示します。
