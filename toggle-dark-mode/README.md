# Toggle Dark Mode

[ダウンロード](https://github.com/31mskz10/alfred-workflows/releases/download/Toggle_Dark_Mode/Toggle.Dark.Mode.alfredworkflow) · [一覧へ戻る](../README.md)

macOSのダークモードとライトモードを切り替えます。

## 必要なもの

- ダークモードを利用できるmacOS
- Alfred Powerpack

## 初期設定

追加のワークフロー設定は不要です。初回実行時にSystem Eventsの操作許可を求められた場合は、許可してください。

## 使い方

Alfredで `darkmode` を入力し、Enterを押します。実行するたびにダークモードとライトモードが切り替わります。引数は不要です。
