# Toggle Dark Mode

[日本語](README.md) · [Download](https://github.com/31mskz10/alfred-workflows/releases/download/Toggle_Dark_Mode/Toggle.Dark.Mode.alfredworkflow) · [Back to list](../README.md)

Switch macOS between Dark Mode and Light Mode. Requires a macOS version with Dark Mode, Alfred 5 or later and Alfred Powerpack.

## Setup

Change the language or keyword under Configuration. If asked to allow control of System Events on first run, allow it.

## Usage

Type `darkmode` in Alfred to see the current mode and the mode to switch to. Press Return to switch to the mode shown. No argument is needed.

## Configuration

Select the workflow in Alfred Preferences and open Configure Workflow.

| Setting | Default | Description |
| --- | --- | --- |
| Language | Auto | Language of the displayed text. Auto uses Japanese when macOS's first preferred language is Japanese, English otherwise. |
| Keyword | `darkmode` | The keyword typed in Alfred. |
