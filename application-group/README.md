# Application Group

[English](README.en.md) · [ダウンロード](https://github.com/31mskz10/alfred-workflows/releases/download/Application_Group/Application.Group.alfredworkflow) · [一覧へ戻る](../README.md)

アプリのグループを作成し、グループ単位でまとめて起動します。グループの作成・編集はAlfred UIの画面で行うため、ワークフローエディタを開く必要はありません。

## 必要なもの

- macOS、Alfred 6 Powerpack
- ウインドウ配置の記録・再現を使う場合: Alfredへのアクセシビリティの許可

Alfred 5を使用している場合は、[旧版（1.0.0、旧名 Launch Applications）](https://github.com/31mskz10/alfred-workflows/releases/download/Launch_Applications_v1.0.0/Launch.Applications.alfredworkflow)を利用してください。旧版のグループはワークフローエディタで設定する方式のため、2.0.0へ更新した場合はグループを作り直してください。

## 使い方

1. Alfredで `ag` を入力してEnterを押すと、グループ一覧の画面が開きます。`ag 仕事` のように続けて入力すると、グループ名で絞り込んだ状態で開きます。
2. グループを選び、Enterを押すか、ダブルクリックします。グループのアプリがまとめて起動し、配置を記録したウインドウは記録した位置とサイズに移動します。

| 操作 | 動作 |
| --- | --- |
| 上下キー | グループを選択 |
| Enter / ダブルクリック / 起動ボタン | アプリを起動し、ウインドウ配置を再現 |
| Shift＋Enter | アプリを起動するだけで、ウインドウ配置は再現しない |
| Command＋N / ＋ボタン | グループを作成 |
| Command＋E / 編集…ボタン | 選択したグループの名前とアプリを編集 |
| Command＋L / 起動時のウインドウ位置を記録ボタン | 選択したグループのウインドウ配置を記録 |
| Command＋Delete / −ボタン | 選択したグループを削除 |
| Esc | 画面を閉じる |

### アプリを選ぶ

グループの作成・編集画面には、`/Applications`、`/System/Applications`、`~/Applications` のアプリが一覧表示されます。検索欄に入力して絞り込み、Enterを押すかダブルクリックすると選択と解除が切り替わります。続けて別のアプリを検索すれば、複数のアプリを順に選べます。選択中のアプリは一覧の上部に表示されます。一覧にないアプリは「その他…」から追加します。Command＋Sまたは保存ボタンで確定します。

### ウインドウ配置を記録する

1. グループのアプリを起動し、ウインドウを使いたい位置とサイズに並べます。複数のディスプレイにまたがって配置しても構いません。
2. `ag` で画面を開き、グループを選んでCommand＋Lを押します。

起動中のアプリの、最小化されていないウインドウを記録します。起動していないアプリの記録は以前のまま残ります。

位置とサイズは、ウインドウがあるディスプレイ内の比率として保存します。ディスプレイの配置や解像度が変わっても、同じディスプレイ上の同じ場所に戻ります。記録したディスプレイが接続されていない場合は、最も近い位置にあるディスプレイに収まるように配置します。同じアプリに複数のウインドウがある場合は、ウインドウのタイトル、次に重なり順で対応付けます。

配置の再現は、アプリのウインドウが開くまで最大20秒待ちます。初回はmacOSのシステム設定 > プライバシーとセキュリティ > アクセシビリティでAlfredを許可してください。許可がない場合は画面下部か通知でお知らせします。

### 保存場所

グループは `~/Library/Application Support/Alfred/AlfredUI/Persist/com.31mskz10.LaunchApplications.ui/variables.json` に保存されます。ワークフローを更新しても保持されます。Alfredの設定同期の対象外のため、別のMacでは作り直してください。

見つからないアプリがあるグループを起動した場合は、見つかったアプリだけを起動し、見つからなかったアプリ名を画面の下部に表示します。Command＋Eでアプリを選び直してください。

## 設定

Alfred Preferencesでワークフローを選び、Configure Workflowで変更します。

| 設定 | 初期値 | 内容 |
| --- | --- | --- |
| 言語 | 自動 | 画面の文言の言語。自動はmacOSの最優先言語が日本語なら日本語、それ以外は英語。 |
| キーワード | `ag` | Alfredで入力するキーワード。 |
